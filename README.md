# 第 29 次提交 举报处理与卖家复核

本次完善了管理员核实举报、处理关联订单和卖家申请复核的流程。卖家能了解商品被下架的具体原因，提交说明和实物照片，并查看管理员的复核结论。

| 功能 | 修改前 | 修改后 |
| --- | --- | --- |
| 举报提交 | 举报进入待处理，商品保持原状态。同一人可以重复提交同一理由的举报。 | 商品仍由管理员核实后决定是否下架。同一举报人、同一商品、同一理由同时只保留一条待处理举报。被驳回后，可以补充新事实再次提交。 |
| 举报下架通知 | 通知包含商品名称和处理备注，备注可以为空。 | 下架原因必填。通知说明具体问题和申请复核的方式，保护举报人的身份和联系方式。 |
| 举报与已付款订单 | 管理员可以处理举报和强制退款，举报记录缺少关联交易的待处置状态。 | 审核时发现已付款订单，会提示「存在交易中的订单」。管理员可查看交易，再单独决定是否强退。强退需要二次确认，服务端重新校验交易和托管状态。 |
| 关联订单取消 | 买家收到退款后，商品按取消流程恢复在售。 | 举报已核实成立时，关联订单取消后仍按原流程退款，商品进入「待管理员处置」。管理员可以确认下架，也可以填写理由解除限制。 |
| 卖家申请复核 | 卖家可以通过「联系管理员」反馈，反馈消息和原举报各自保存。 | 卖家可在「我的商品」查看原举报选择的类别和管理员填写的下架原因，填写复核说明并上传照片。材料关联到原举报及下架处置。每份申请可附最多 3 张 JPG 或 PNG，单张最多 5 MiB，待复核时可补交照片。同一次下架处置只允许申请一次复核。 |
| 下架商品的访问 | 举报下架商品会退出公开在售列表，其他用户仍可能通过收藏或商品编号看到详情。 | 卖家本人和管理员可查看商品详情及复核材料。其他用户从收藏或旧详情入口访问时只看到「商品暂不可用」，服务端拒绝购买。 |
| 复核结论与记录 | 管理员可直接恢复举报下架的商品，缺少单独的复核结论和理由记录。 | 管理员可以对照原举报、下架理由、卖家说明和照片，选择「恢复上架」或「维持下架」。两种结论都记录理由、处理人和时间，并通知卖家。恢复前检查商品和卖家是否符合条件，以及是否还有其他有效的下架处置。 |
